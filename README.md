# The Daily Cafe & Bistro (Kolkata) — Multi-Page Website ☕✨

A complete, modern, aesthetic, and responsive **5-page website** built for **The Daily** (The Daily Cafe & Bistro), South Kolkata's beloved European-style cafe & bistro located at **5, Satyen Dutta Road, Lake Market, Kalighat / Desapriya Park, Kolkata, West Bengal 700029** (Landmark: same lane as Maharaja Tea Stall, off Rash Behari Avenue).

---

## 🌟 Highlights & Key Features

- **🍽️ Complete 5-Page Multi-Page Architecture**:
  - **1. Home (`index.html`)**: Ambient hero banner, live Open/Closed badge based on Kolkata time, 3-way ordering hub (Direct / Zomato / Swiggy), curated menu highlights with instant Add-to-Cart buttons, story snippet of Chef Urvika Kanoi & Bombay amigo `@cafeduco`, popular times graph (6 PM – 11 PM peak), real Google reviews showcase (4.3 ★ with 1,673+ reviews), and interactive location guides.
  - **2. Menu & Online Ordering (`menu.html`)**: Complete 30+ dish database categorized into Specialty Coffee & Beverages, All-Day Brunch, Pastas & Steaks, Small Plates & Tapas, Burgers & Bowls, and Artisanal Desserts. Features live instant search, dietary filters (Veg, Non-Veg, Chef's Special), in-card quantity steppers, optional customization modal, and 1-tap direct add-to-cart.
  - **3. Our Story (`about.html`)**: The culinary journey of Chef Urvika Kanoi, European bistro culture, fresh local produce philosophy, the surprising spacious sunlit interior, four guiding pillars, and the partnership with Bombay sister cafe `@cafeduco` in Bandra.
  - **4. Reservations (`reservations.html`)**: Real-time table booking form with validation (Date, Time slot, Guest count, Seating preference, Dining occasion), generating an official verified Booking Confirmation Ticket (`#TD-RES-XXXX`) with a 1-click WhatsApp confirmation to `+91 80170 99950` and print receipt.
  - **5. Contact & Location (`contact.html`)**: Full physical address, clickable phone dialer (`080170 99950`), embedded interactive Google Map, navigation landmarks from Kalighat Metro & Maharaja Tea Stall, live operating schedule, popular times chart, and direct inquiry form.

- **🛍️ Unified Slide-Out Cart Drawer Across All Pages**:

## 🚀 How to Run & View

### Option 1: Direct in Any Web Browser
Simply double-click `index.html` or drag it into Google Chrome, Microsoft Edge, Mozilla Firefox, or Safari. All 6 pages navigate seamlessly via standard relative links.

### Option 2: Local Web Server (Optional)
```bash
# Using Python:
python -m http.server 8000

# Using Node.js:
npx serve .
```
Then visit `http://localhost:8000/`.
